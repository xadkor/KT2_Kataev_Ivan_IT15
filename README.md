# Катаев Иван, ИТ-15

Тестовое задание на стажировку Frontend, KODE, 2025 (копия в каталоге Hexlet):
https://github.com/Hexlet/ru-test-assignments/blob/main/frontend/kode/trainee-test-frontend.md

Это учебная работа КТ2: приложение «список сотрудников» по макету.

## Что делаю
1. Проект на Vite + React + TypeScript, React Router, Axios.
2. Загрузка списка сотрудников с API; экран загрузки и экран ошибки (в том числе ответ 500).
3. Список сотрудников: фото, имя, никнейм, департамент.
4. Вкладки департаментов с фильтрацией на клиенте.
5. Поиск по имени, фамилии и нику; сообщение «ничего не найдено».
6. Сортировка сотрудников по алфавиту и по ближайшему дню рождения с учётом перехода на следующий год.
7. Страница деталей сотрудника на отдельном маршруте: фотография, имя, никнейм, должность, департамент, телефон и дата рождения; предусмотрена ссылка возврата к списку.
8. Адаптивная вёрстка без готового UI-kit.
9. README: как запустить, что сделано, как проверял.

## Что не делаю и почему
Тёмная тема, локализация, кэш запросов на 5 минут, отслеживание сети и работа офлайн, GitHub Pages, серверная фильтрация, задания со звёздочкой. За 6–8 часов не успеть, основной сценарий от них не зависит.
