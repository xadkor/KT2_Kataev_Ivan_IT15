# Катаев Иван, ИТ-15

Тестовое задание на стажировку Frontend, KODE, 2025 (копия в каталоге Hexlet):
https://github.com/Hexlet/ru-test-assignments/blob/main/frontend/kode/trainee-test-frontend.md

Это учебная работа КТ2: приложение «список сотрудников» по макету.

## Декомпозиция задания (план из первого коммита)
1. Проект на Vite + React + TypeScript, React Router, Axios.
2. Загрузка списка сотрудников с API; экран загрузки и экран ошибки.
3. Список сотрудников: фото, имя, никнейм, департамент.
4. Вкладки департаментов с фильтрацией на клиенте.
5. Поиск по имени, фамилии и нику; сообщение «ничего не найдено».
6. Сортировка по алфавиту и по ближайшему дню рождения с блоком года.
7. Страница деталей на отдельном маршруте.
8. Адаптивная вёрстка без готового UI-kit.
9. README: как запустить, что сделано, как проверял.

## Что сделано
- Загрузка списка, экран загрузки и экран ошибки.
- Список сотрудников, вкладки департаментов, поиск, сообщение «Мы никого не нашли».
- Сортировка по алфавиту и по дню рождения с блоком года.
- Страница сотрудника по ссылке `/user/<id>`: фото, имя, никнейм, департамент, дата рождения, телефон (ссылка `tel:`), кнопка «назад».
- Адаптивная вёрстка без UI-kit.

## Что не сделано и почему
Тёмная тема, локализация, кэш запросов на 5 минут, отслеживание сети и работа офлайн, GitHub Pages, серверная фильтрация, задания со звёздочкой: за 6–8 часов не успеть, основной сценарий от них не зависит.

Известный недочёт: после перехода на страницу сотрудника и возврата сбрасываются выбранная вкладка и поиск (дополнительное задание «Сохранение состояния» не выполнено).

## Как запустить
1. Установить [Node.js](https://nodejs.org/) (проверял на v24.11.0).
2. Скачать репозиторий и перейти в папку:

```bash
git clone https://github.com/xadkor/KT2_Kataev_Ivan_IT15.git
cd KT2_Kataev_Ivan_IT15
```

3. Установить зависимости и запустить:

```bash
npm install
npm run dev
```

4. Открыть адрес из терминала (обычно `http://localhost:5173`). Если `localhost` не открывается, использовать `http://127.0.0.1:5173`.

Сборка для проверки: `npm run build`.

## Как проверял
Вручную в браузере Chrome: загрузка списка; каждая вкладка департамента; поиск по имени, фамилии, никнейму и пустой результат; обе сортировки; открытие страницы сотрудника по клику и по прямой ссылке; кнопка «назад»; экран ошибки при отключённом интернете; `npm run build` без ошибок.
